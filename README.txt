My Budget Personal V21 — Dedicated Paycheck Calibration

Upload index.html, sw.js, icon.svg, and manifest.webmanifest to your PERSONAL GitHub repository root. Export a JSON backup before updating. Do not upload to the commercial repo.

Open Paychecks > Calibrate paycheck, or Settings > Open Calibration Tool. Enter 2–3 current-period paystubs with different gross pay amounts; add or edit newer paystubs over time.

State tax estimates are learned from observed withholding and may be inaccurate outside the sample range. Other withholding adjustments use the latest saved stub.
